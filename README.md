### Key Menu Options Explained Simply:

#### 1. Device Pairing: Connects the app to the user's wireless earbuds, headphones, or smart hardware via Bluetooth.

#### 2. Audio Profile Customization: Fine-tunes equalizers and sound levels based on personal listening preferences.

#### 3. Emergency Bypass (Safety Toggle): A crucial safety feature that automatically lets urgent sounds (car horns, sirens, alarms) break through active noise cancellation.

#### 4. Daily Focus Goal: Lets users set custom daily targets for quiet time (e.g., 7.5 hours a day).

#### 5. Push Notifications: Controls alerts for scheduled focus sessions, break reminders, or automated mode changes.

#### 6. System Updates: Keeps the app's AI audio filters up to date with the latest sound-processing software.
